# 工作台 Workbench

> 一个 DSH Web GUI 客户端插件：把只有对话的界面，变成一个可以**管理多个项目、读懂一次开发、并把它总结成文档**的工作台。

## 这是什么

装上之后，左侧边栏会多出 **工作台** 一行：

```
侧边栏
  ├─ 工作台            → 工作台面板（首页磁贴墙）
  └─ 每个模块一行       → 直接进入该模块（行首是灰/绿状态点）
        └─ 点模块卡片 → 对话控制台：三栏 + 自由增删窗格
        └─ 每日新闻   → 新闻阅读器：主题轨 + 新闻流 + 详情
        └─ 框架笔记   → 节点式思维导图（不挂钩任何对话）
```

「新建模块」磁贴下面有三个小胶囊：**游戏开发 / 每日新闻 / 框架笔记** —— 三种模块是三种不同的东西，所以新建时可以直接选。

打开一个模块，中间栏是三栏控制台：

| 窗格 | 回答的问题 |
| --- | --- |
| **对话节点树** | 这次开发是怎么走的？—— 分支图 + 项目总览 + 轮次时间线 |
| **对话轮次汇总** | 这一轮到底做了什么？—— 输入 / 思考 / 回复 / 代码 / 参数 / 改动文件 |
| **资源仓库** | 还够用吗、花在哪了？—— 余额环 + 各项目消耗对比 + 逐轮占比 |

### 框架笔记模块（节点式思维导图）

一个不挂钩对话、只挂钩你自己思路的模块：**一条树 = 一张图**，而且**一个模块下可以有很多张图**；每个节点里都能写文字、贴图片。

| 区域 | 内容 |
| --- | --- |
| **顶栏（两行）** | **第一行**：返回 · 标题 · 大纲 / 检查器（面板开关）。**第二行**：结构（4 种预设）· 连线（曲线 / 直角 / 直线）· 配色（4 套）· **文件（一个按钮，内含新建 / 保存 / 打开 / 导出）** · 撤销 / 重做 / 整理 · **适应画布** |
| **左栏 · 文件总览** | 每篇笔记一行：**当前编辑的那篇在最上面并标「当前」**，其余按**最近打开**排（最多 10 条）；点一下切换、**右键删除**；一行里带节点数 / 图片数 / 时间 |
| **中间 · 画布** | 无限画布：拖空白平移、**滚轮缩放**（Ctrl+滚轮左右移动）；Ctrl+0 实际大小、Ctrl+加减 缩放；卡片是节点，连线走 SVG |
| **右栏 · 检查器** | 选中节点的：标题、备注、图片、形状、颜色、折叠、加子节点、删除 |

- **每篇笔记各自保存在本地**：一篇 = 一棵独立的树，连同它的结构 / 连线 / 配色一起存进 localStorage，导出与打开也按篇来。左栏原来列的是「这棵树的节点」，但那本来就是中间那张图 —— 换成**文件总览**之后，「我正在编辑哪个文件、最近开过哪些」才第一次有地方可问；旧存档（只有一棵树）在第一次打开时会迁移成「第一篇笔记」，不丢内容
- **文件是有名字的**：新建时自动起一个「笔记 MM-DD HH:mm」，随时可在检查器里改。**存出来的文件名就是它** —— 以前用的是模块名，于是每一篇都存成 `框架笔记.json`，在文件管理器里根本分不出哪份是哪份。**老存档里的无名笔记会在第一次打开时被补上名字**（有中心节点标题就用标题，否则按创建时间生成），所以升级后不会继续看到「未命名笔记」
- **图片跟着卡片缩放**：图片块用 flex 撑满卡片除文字以外的那块空间，所以拖大卡片时图片跟着变大（`填满` / `完整显示` 仍由 object-fit 决定）。手动尺寸的卡片**不再把图片高度叠加到总高上** —— 否则拖大时卡片会越拖越高，永远追不上指针
- **和桌面是同一套材质**：这一屏不画自己的纸 —— 画布是一块**毛玻璃板**，卡片表面、连线、文字全部走宿主 token，所以明暗、玻璃浓度、圆角、字号都跟着桌面设置走，配色只决定强调色。桌面背景（极光 / 图片 / 视频）从下面透上来，和对话控制台、每日新闻一样
- **4 种结构预设**：思维导图（中心在中间、分支左右交替）· 逻辑图（全部向右、紧凑）· 组织结构图（向下分层、一层一行）· 树形图（一格一行的档案树）。布局是**纯函数**：同一棵树在 4 种结构下都能算出来，而且**任意两张卡片都不重叠**（这一条是被自检按矩形相交严格断言的，不是感觉）
- **为什么没有时间轴与鱼骨图**：这两种结构曾经在顶栏里，返工过两次 —— 几何最终是修对了（45° 骨、零重叠、不横穿卡片），但它们本质上是**对"顺序"的呈现**，而这里是一张自由画布，树长什么样由读者决定。留两个按钮去摆读者没要求的版式，比不提供更糟，所以从顶栏撤掉。它们的布局函数与文案仍然留在代码里：用它们时存下的笔记带着 `layout: 'timeline'` / `'fish'`，打开时会**安全回落成思维导图**，而不是渲染失败
- **时间轴 / 鱼骨图为修过什么**（保留在代码里，但不再出现在顶栏）：两种结构各返工过两次，最后都做到了几何正确 —— 时间轴的事件沿轴依次排开、成链的子节点背离轴线；鱼骨图的每根骨头从脊柱以**严格 45°** 斜到卡片近角。还修掉了两个真 bug：① 固定缩进 + 从父卡片起点摆孙辈，会让「既有兄弟又有孩子的节点」把孙辈压在叔叔的卡片上（深度 3 的树上实测是两个**完全相同的矩形**）；② 它们自己画了轴与骨，却又给每层补了一条从父卡片中心出发的长曲线，那些曲线横穿整张图、也从卡片底下穿过 —— 就是「线跑到节点里面去了」的来源，现在布局层不再产出这些边。这两条都留在自检里（「非父子重叠必须为 0」、「布局不得产出 stack 连线」）
- **卡片会随文字变高，也能手动拉伸**：贴进一段长备注，卡片自己长高（有上限，免得一个巨大节点把整张图挤小；行数按字宽**估算**而不是测量 —— 布局是纯函数，量 DOM 会让同一棵树在两次渲染间抖动）。右下角的**拉伸角**可以拖出任意尺寸，手动尺寸优先于自动。字体大小够用就不需要拉伸，而拉过之后这张卡片就不再随文字变
- **加子节点的入口**：`Tab`（加子节点）· `Enter`（加同级）· 右键菜单 · 检查器里的「加子节点」。加完直接进入改名
- **拖动一整枝**：按住一个节点拖动，它和它下面的整枝一起走，**连线实时跟着变**（枝内的线只是平移、形状不变；枝外的线一端不动、另一端跟随），抬手才落盘；「整理」一键回到结构自动排布
- **节点里能放图片**：文件拖到卡片上、或直接粘贴；可以切「裁剪填满 / 完整显示」、拖高度（56–240）。图片以 Blob 存 IndexedDB，存档里只留 key —— 一张照片的 data URL 会吃掉整个工作台的 localStorage 预算
- **文件保存 / 读取 / 导出**：**保存**成本地 JSON（图片内嵌 base64，唯一能完整还原的格式）；**打开**可以读 `.json` / FreeMind `.mm` / `.opml` / Markdown 大纲（导入是替换，但**一个 Ctrl+Z 就能撤销**）；**导出**可以出 **XMind `.xmind`**（结构预设一起带过去）、FreeMind `.mm`、OPML、Markdown。解析器不依赖 DOMParser，认不出的文件会说明原因而不是给一张空图
- **文字直接写在卡片上**：双击改名（Enter 确认 / Esc 还原原文），`Tab` 加子节点、`Enter` 加同级、`Delete` 删；长一点的说明写在检查器的「备注」里，卡片上用两行显示
- **撤销 / 重做**覆盖每一次编辑（40 步快照，按「整段输入」而不是按每个字母）；**视图按模块记住**：缩放、平移、两条侧栏的开合都留到下次打开
- ⚠️ **这一版去掉了压感手写**：原来的画笔 / 橡皮 / 压感 / 参考图已下线，节点图片取代了参考图的位置；旧存档里的手写笔迹**仍然保留在数据里**，只是不再显示

### 每日新闻模块

一个不挂钩对话、只挂钩网络的模块。打开后是**一条关键领域导航条 + 两块毛玻璃面板**：

| 区域 | 内容 |
| --- | --- |
| **关键领域**（顶部导航条） | 横向的领域切换，像新闻站的分区栏：当前领域高亮并带下划线，悬停出现 ✎ 进入编辑；末尾是 **`+ 自定义`**。点 ✎ 或 `+` 会从导航条下方**浮出**编辑面板（改名、关键词胶囊、来源勾选、语言、删除），浮层**不挤压**正在读的内容 |
| **关键领域新闻速览**（左） | 顶部是 **最新播报** 滚动带（最新 14 条自动匀速滚动，悬停即停）；下面是**头版**：报头 + 一条头条 + 两条次条 + 行式列表，三种密度（列表 / 网格 / 紧凑）。打开时**自动选中头条**，右边立刻就有内容可读 |
| **新闻原文**（右） | 选中那条所在的**文章页面原文**：类目行 → 大标题 → 导语 → 署名行（作者 · 媒体 · 时间）→ 封面图 → **正文分段**；下面是同期报道、打开 / 复制 / 搜索，最后是逐来源耗时。译文按段落在原文上方对照 |

- **布局改过一版**：主题切换原本是左边一列，占掉三分之一宽度却只在切领域时用一次。现在它是一条横向导航（跟 IGN 那种分区栏一样），把宽度全部还给新闻本身；两栏之间的接缝仍可拖动，双击复位，宽度按模块保存（旧的三个栏宽会自动迁移成两个）

- **跟随桌面，和对话后台一样**：这一屏不画自己的背景 —— 桌面背景（极光 / 图片 / 视频）从下面透上来，「控制台流光」开关同时管两屏，配色 / 玻璃 / 圆角 / 字号全部走同一批 token；入场也是同一条两段式（先屏幕缩放淡入，落位后再内容扫入）
- **最新播报会自己滚**：顶部那条带子自动匀速滚动最新的 14 条（跨所有领域），**悬停或键盘聚焦即停**，方便点开；速度是按「像素/秒」定的，所以条数多的时候是滚得久而不是滚得快。它只动 `transform`（不重排），在 `减少动态` 下完全停住并交回一条可手动拖动的带子。静止截图里第一张卡片看着像被切了一块 —— 那是两侧的渐隐遮罩，不是 bug
- **像头版一样排版，不是一列等大的行**：头条拿最大字号和通栏大图，两条次条并排，其余走行式并在右侧留一张 68px 方图 —— 一屏扫下去就知道什么重要。字号梯度 21 / 14.5 / 13.5 / 12.5px，配图位置与摘要行数跟着层级一起变；列表密度上还有一条**报头**（日期 · 栏目 · 条数）。完整梯度表在 `REFERENCE.md`
- **卡片配图**：订阅源几乎都不给图，所以按需从文章自己的 `og:image` 取 —— 只为**即将画出来的那几条**批量请求，Host 一旦拿到完整的 `og:image` 标签就**断开连接**（不必把整页 500 KB 拖下来），结果按文章 URL 缓存 6 小时并写回归档。第二次打开是零请求。抓不到的条目不显示灰色占位框，而是干干净净地没有图
- **右边是文章原文，不只是摘要**：`op=article` 除了 `og:` 元数据，还会从页面里**抽出正文段落**（去掉导航/广告/脚注，只留像句子的段落，最多 18 段约 6400 字）与署名（作者 · 媒体 · 时间）。付费墙或拒绝非浏览器访问的页面读不到正文时，界面**明说**「这个页面没有给出可读的正文」，而不是让你以为是自己看漏了。这一条只在**你点开的那一条**上做，不会为列表里每条都去下整页
- **英文标题自动中文对照**：英文条目在原文上方多出一行中文，原文一个字不少地留在下面。翻译**不走模型**（不花你的 token），用的是公开机翻端点 + **本地持久缓存**：一条标题译过一次就永远不再请求；`中译` 开关在工具条上（快捷键 `T`），默认开，关掉后每条英文仍留单独一个「译」按钮
- **当日全球大事件**：默认从 Google 新闻头条（中/英）、BBC、NPR、半岛电视台取当日头条；被多家同时报道的故事在播报带上会带「N 家媒体报道」徽章（门槛 3 家）—— 覆盖它的媒体数量，是「大事件」最诚实的定义
- **自定义关键词 / 领域**：内置 AI 领域、游戏领域、科技前沿、科学发现、财经市场五个主题。每个主题可以用关键词（交给 Google 新闻搜索）和勾选来源两种方式定义；最多 12 个主题、每个 8 个关键词。改关键词**即时生效**（7 天归档存在本地，切主题不重新抓取）
- **最多保留 1 周**：抓取窗口可选 今日 / 3 天 / 7 天，但**归档永远只留 7 天**。Host 与浏览器各强制一次：Host 决定「一次刷新能带回什么」，浏览器决定「关掉一周再打开还剩什么」
- **10–100 条，可拉伸，按主题各算**：条数是 10–100 的拖动滑杆（步长 5），**每个主题各自**取这么多条（所以每个标签页都填得满）；改条数只裁剪本地列表、不重新抓取；三栏之间的**接缝可以直接拖**（双击复位），宽度按模块保存
- **25 个已验明可用的来源**：每条都实测过才写进目录（会 403 或返回 HTML 的不收录）；中文源包括 IT之家、Solidot、cnBeta、36氪
- **只为看得懂而联网**：默认不抓正文。点开一条时才按需读取那一页的 `og:` 标题 / 摘要 / 配图；失败（403 很常见）就退回订阅自带的摘要
- **诚实的状态行**：显示本次抓到的条数 / 覆盖到的天数 / 参与来源数 / 耗时 / 失败来源数；详情栏的「来源状态」列出每个来源的毫秒数与失败原因。整体抓取有 **15 秒上限**，到点就先显示到手的新闻，剩下的在后台继续抓并进缓存（下次切主题秒开）
- **版面抄的不是口味**：间距梯、发丝线层级、单一强调色来自 **Linear**；阅读流的行式排版、类目标签、来源行来自 **WIRED**。理由与逐条对应写在 `REFERENCE.md`

> ⚠️ **需要重启一次 DSH**：抓取在 Host 半（`news.js` + `/workbench-news` 路由），而 Host 半代码只在进程启动时读一次。客户端半改完会自动热重载，但**首次装上这一版必须重启一次应用**，否则新闻流是空的。

> ⚠️ **在需要代理的网络里**：Google 新闻 / BBC / 半岛电视台必须经代理才能访问。本模块**自己找代理** —— 先看环境变量（`https_proxy` / `http_proxy`，也就是 DSH 自己的策略输入），再读 Windows 的 Internet 设置（`ProxyEnable` / `ProxyServer` / `ProxyOverride`），用 `CONNECT` 隧道直连，代理挂了自动改走直连。所以控制面板里配好代理就够了，不用改插件。如果确实连不上，界面会直接把原因说出来，并提示可以在 `~/.dsh/.env` 里写 `https_proxy`。

### 股票市场模块（指数看板 + 点进板块看全部个股）

一屏回答两个问题：**全球主要指数现在什么水平**，以及**某个板块内部的个股各自怎么样**。

| 视图 | 内容 |
| --- | --- |
| **看板** | 每个市场一张磁贴：最新价、涨跌、涨跌幅、日内迷你走势 |
| **表格** | 同一批指数排成一张密集表，便于横向比较 |
| **板块** | 10 个可点进去的板块：沪市主板 / 科创板 / 深市主板 / 创业板 / 北交所 / 港股主板 / 港股创业板 / 纳斯达克 / 纽交所 / 美国交易所 |

- **点任意板块卡片**：进入该板块的**成分股表** —— 代码 · 名称 · 最新价 · 涨跌幅 · 成交额 · 换手率 · 市盈率 · 总市值 · 振幅 · **今日区间**（现价在当日高低之间的位置）
- **表内可排序**：涨幅 / 成交额 / 换手率 / 总市值 / 价格 / 代码，点表头切换升降序；**可搜索**：按代码或名称即时过滤
- **计数行如实说清楚规模**：例如「板块共 1,846 只，显示 100 只（完整名单）」—— 板块本身是完整名单时这么写；港股 / 美股那种全量里混着大量窝轮与票据的，写「活跃榜 · 按涨幅取前 100 名」，**不假装它是全部**
- **缺值显示破折号，绝不显示 0**：0 是一个会被当真的价格；没有价格的行（窝轮、票据、退市代码）在 Host 侧就被过滤掉了，所以第一屏不会是空白

> ⚠️ **需要重启一次 DSH**：板块与成分股走 Host 半的 `/workbench-stocks?op=markets|members`，Host 代码只在进程启动时读一次。

> **数据来源与实测**：指数报价优先 Yahoo `chart`、失败回落腾讯 `qt.gtimg.cn`；板块成分股走东方财富 `push2.eastmoney.com`。本机实测 Yahoo 的 `v7/quote`、`v1/screener` 与 `v8/chart` **全部 403**（指数那一半实际一直靠腾讯兜底），而东财**直连 200**、200–400 ms 返回，且天生支持「按板块列成分股」。三条实测出的硬约束写在 `stocks.js` 文件头：只有 `fid=f3` 真的会排序、`pz` 上限 100、港美股全量里混着衍生品。

### 其他主要功能

- **模块图标按公开规格构造**：桌面磁贴上的五个图标（对话后台 / 框架笔记 / 每日新闻 / 综合研究台 / 未知模块）照 Lucide·Tabler·Feather 的 24 网格规范来过 —— 2px 安全区、1.5px 等宽描边（Heroicons 的 outline 粗细）、圆头圆角、无填充、**只用直线段**、坐标取整、角度只取 45° 的整数倍、元素间距 ≥2px，且每个图标都占满安全区的 90%（这一条是 review grid 逼出来的：初稿从 65% 到 100% 都有，并排就像五个图标包拼的）。每个图标有一句先定好的隐喻，`REFERENCE.md` 里有表
- **总结导出**：把对话按主题压缩，用「**现象 → 根因 → 解法 → 结果**」模板生成**一页一主题的 PPT**（真表格，不是文本框摆的假表格）
- **框架笔记**：独立窗口的**节点式思维导图** —— 4 种结构预设、一个模块下可以有很多篇笔记、节点里可以写字和贴图、撤销重做与逐模块记住的视图（详见上面「框架笔记模块」一节）
- **绑定 / 解除绑定**：控制台默认跟随当前对话，也可以显式钉死在某个会话上
- **液态玻璃**：正在运行的模块带克制的流光边缘（7 套配色）
- **界面可调**：10 种卡片排布、正方形/长方形比例、4 档毛玻璃材质、7 套流光配色

| 前提 | 说明 |

> 下载，解压到本机后用「方式二」把 `dependencies` 指向解压出来的目录即可（`link:` 或 `file:` 都行）。
>
> **公司网络拦 github 怎么办**：让 git 走你的代理即可，例如

### 方式二：下载 zip 手动安装

1. 下载本仓库（Code → Download ZIP）或 `git clone`
2. 解压/放到一个**不会被随手删掉**的位置（profile 里存的是**绝对路径**）
3. 编辑 `<profile目录>\package.json`，两处都要改：


> **最容易踩的坑**：同一台机器可能有 `desktop`、`web` 多个 profile，而桌面应用读的往往不是你最先看到的那个。装错了**不报错、插件也不出现**。查准的办法见 [QUICKSTART.md](QUICKSTART.md) 第 2 步。

### 启用后

- 新增/删除 bundle **必须重启 DSH**（bundle 列表只在启动时读一次）
- 只改 `client.js` 的话**不用刷新**：`dsh-client-hmr` 每 500ms 轮询文件，检测到变化就通过 SSE 把新 bundle 推进页面并就地换掉（`Ctrl+R` 也可以）
- 改 `index.js` / `news.js`（Host 半）**必须重启应用**：Host 半的模块只在进程启动时 import 一次，页面刷新帮不上
- 出问题先从 `dsh.profile.bundles` 里删掉那一项 —— **先禁用总是安全的**

## 为什么是零依赖

界面只有一个文件在做事（`client.js`），它只引用 DSH **自带的**两个客户端包：

```
@deepseek-ai/dsh-client-ui-layout
@deepseek-ai/dsh-client-ui-session
```

Host 半（`index.js` + `news.js`）也只用 Node **内置**模块（`node:http` / `node:https` / `node:tls` / `node:net` / `node:zlib` / `node:dns` / `node:child_process`）。新闻的代理隧道是自己拿 `node:tls` 拼的 —— 这不是喜欢造轮子，而是 `fetch` 在这台机器上就是不通：它既不读 Windows 的代理设置，也不接受运行期塞进去的 `https_proxy`（Node 只在启动时读那个变量），而插件没法在运行期改启动参数。同源主机路由 + 自带隧道，是这个环境下唯一能自己站住的做法。

所以**不需要联网、不需要 `pnpm add` 任何东西** —— 这也是它能整包拷走、或直接用 git 地址安装的原因。

它同样遵守几条底线：

- **不自己存会话数据**：读会话事件窗口与出厂 token 投影
- **不发模型请求**：所有摘要都是本地抽取式推导，原文永远可展开查看
- **不劫持宿主布局**：只用一个侧边栏槽位 + 一个主槽位

## 自检

```powershell
node test/render-check.cjs       # 界面与状态：all render checks passed
node test/host-route-check.cjs   # Host 路由与引擎：all host route checks passed
node test/preview-news.mjs       # 出图 + 量尺寸（开发用，不是断言）
node test/preview-notes.mjs      # 框架笔记 6 种结构各出一张 PNG + 一张合影（开发用）
```

`render-check.cjs` 用一个有状态渲染器在**三个真实会话日志**（最大 8000+ 事件）上跑断言，覆盖：注册与槽位、10 种排布、卡片比例与大小、控制台预设与窗格、分支图、绑定语义、**框架笔记（6 种结构的排布都不重叠、节点增删改查、图片、撤销重做、逐模块持久化）**、总结导出的 PPT 结构、**每日新闻阅读器**（模块上架与一次性种子、三栏结构、条数 10–100 钳制、7 天归档、大事件门槛、关键词/来源/主题编辑、**`+` 新建主题必须先点开才有输入框**、栏宽拖动与复位、抓取失败降级、路由缺失时提示重启、15 秒截止与代理提示、**跟随桌面（同一套外壳 + 流光开关关掉时那一层不渲染）**、**中英对照（批量、去重、跳过中文、缓存持久化、开关与单条按钮、详情栏双语、回显不算译文）**、**头版层级（一条头条 / 两条次条 / 其余行式、不足三条不硬造头条、报头、方格与方图、大事件配图）**、**配图只取一次且只取要画的那些、结果写回归档**），以及**性能路径**（关键帧不许插值圆角、`filter` 动画不许挂回容器、自动翻页不许回来、新闻关键帧只许动 transform/opacity）。

`host-route-check.cjs` 是它的镜像：把真的 `index.js` 交给一个假的 cordis ctx，捕获它注册的路由，再用**真的 `node:http` 服务器**去请求它们。它覆盖的是**只有在 Host 半才会出错**的那些事 —— 插件有没有声明 `inject`（漏了会让路由根本没注册，`/workbench-media` 会返回 SPA 的 404 而不是它自己的错误）、同源围栏（抓取 / 翻译 / 配图三条都查）、JSON 形状、内网地址围栏（配图路线一次收一批地址，所以逐条围栏、逐条计数，一条坏的不能毁掉整批）、`news.js` 里那条「每个主题各取 limit 条」的纯函数规则，以及翻译引擎的去重 / 跳过中文 / 非法目标语言收口。

`test/glyph-path.cjs` 是一段很小的 SVG 路径读几何的工具。有意思的图标规则都是**几何**的（在安全区内、整单位坐标、角度是 45° 的整数倍），而几何没法用正则去查；第一版的 review grid 用「两个数字一组」的笨办法把 `research` 量成 14×14（实际 18 宽），因为 `H` 只吃一个参数。现在网格与自检共用这一份实现。

`tools/preview-glyphs.mjs` 是图标这一块的「看得见」：把所有模块图标排在一张网格上，三档尺寸、深浅两种底、构造检查（网格 / 安全区 / 包围盒）、以及放进真实磁贴的样子。参考材料管这一步叫不可跳过 —— 单个图标看不出问题，一排就能看出来。

`preview-news.mjs` 补上「看得见」这一格：把真的 `client.js` 渲染成 HTML + 真的 CSS，交给无头 Chrome **出图**并**量出每个窗格的矩形、每张卡片的高度与横向溢出像素**（`--view list|grid|compact` 可以分别出图）。这不是洁癖 —— 新闻面板曾经复用了设置面板的 `.wsb-field`（一个 `52px 1fr 30px` 的 grid），于是标签被压成 52px、来源行横向挤在一起；**逻辑断言全绿，只有看图才发现**。后来「头版」这一版也是靠它看出来的：网格密度在窄栏里只排得下一列，看起来跟列表没区别。

`preview-notes.mjs` 是框架笔记的同一格，而且它一上线就抓到了三个「断言全绿但界面是坏的」：**屏幕进场动画被无头 Chrome 的虚拟时钟截在 `opacity:0`**，于是截图拍到的是首页极光而不是思维导图；序列化器把 `d` / `x1` / `y1` 丢掉了，**每一根连线和每一根鱼骨都是看不见的空路径**（数量断言照样 14/14 通过）；节点卡片的备注行被卡片自己的下边缘切掉几个像素。它还带四条自我校验：连线必须有几何、guides 必须有几何、DOM 里不许有重叠卡片、不许有卡片跑到画布外 —— 有就抛错，而不是出一张看起来没问题的图。`--theme ink --branch elbow` 可以换成深色配色与直角连线再看一遍。

## 已知边界（诚实说明）

- **真实帧率未测量**：性能修复是按根因逐条消除重绘/重栅格化并用断言锁住的，但没有 profiling 数据
- **Office 真实渲染未验证**：导出的 PPT 用 `python-pptx` 独立验证了结构（33 张真表格 / 392 单元格 / 0 个 `[object Object]`），但本机没有 Office/LibreOffice 的真实渲染对照
- **手写批注已下线**：原来的压感笔、橡皮与「参考图浓度」在这一版被节点 + 节点图片取代。旧存档里的笔迹**仍在数据里**（读档时只补字段、不删字段），但界面不再渲染。这是取舍：需要手写批注的人会想念它
- **节点图片与手感需要真人上机确认**：图片插入后的显示、几百个节点的大图性能、拖拽平移的手感都只有自动化断言（矩形、状态、路径）在守，没有手感数据
- **新闻来源会变**：25 条来源都是实测通过才写进目录的，但外部站点随时可能改地址、加 Cloudflare 或下线。抓不到时界面会点名是哪个来源、失败原因是什么，不会假装成功
- **新闻的 Host 半改动要重启**：`dsh-client-hmr` 只热重载浏览器半；`index.js` / `news.js` 属于 Host 半，必须重启应用。这是 DSH 的设计（`dsh-hmr` 的 `root: []`），不是这个插件能绕过的
- **代理探测是显式的、不是全能的**：读环境变量与 Windows Internet 设置，并带 DNS 解析检查；它不处理 PAC 脚本、SOCKS，也不读别的平台的系统代理。这些情况下请设 `https_proxy`
- **`limit` 是「每个主题」**：这样每个 tab 都能填满你自己设的条数（条数 100 + 6 个主题时一次抓取最多带 600 条回来）。代价是首次抓取的 payload 变大，归档上限相应提到 1200 条
- **机器翻译是尽力而为的**：用的是公开免费端点（Google `gtx` 优先，MyMemory 兜底），限流时会给不出译文 —— 界面会把「翻译服务：HTTP 429」直接说出来，而不是假装没有英文。已缓存的条目不受影响（缓存键是原文，存在本地），所以日常读报只会为**没见过的标题**付一次请求
- **译文的正确性由端点负责**：本项目不校对机翻结果，也不该假装校对了。但有一种失败会被拦下并重试：端点在压力下会把原文原样回给你 —— 那会被判为「未翻译」而不是存成一个和原文一样的「译文」（否则界面上会把同一句话印两遍）
- **配图依赖第三方防盗链策略**：抓不到就是没有图，不显示占位框。首次打开一屏新闻会顺带抓 8–18 个缩略图，之后按文章 URL 缓存 6 小时
- **正文抽取是「够用」而不是「完美」**：一套真正的 readability 要上千行启发式规则，而且仍然会在半个互联网上失手；这里要的只是让你在决定要不要打开原文之前读到它说了什么。所以它按 `<article>` / `<main>` 找最像正文的区域，保留像句子的段落，其余丢掉。排版怪、正文在非 `<p>` 里的站点会拿不到正文（界面会说明）
